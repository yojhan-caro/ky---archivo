# KY SpA Archivo

Bitácora de la empresa **KY SpA**: carpetas por área (Empresa, Pulso, Producción, Ventas, Meta, Marca, Clientes, Pendientes), con notas, tareas y fichas editables. Se instala como app en la tablet o el celular y funciona sin internet.

- **Tus datos:** se guardan solo en el dispositivo (localStorage), no en este repositorio.
- **Respaldo:** botón *Respaldo* → *Descargar respaldo*. Para recuperarlo: *Importar respaldo*.
- **Contenido base:** `data.js`. Si agregas una carpeta nueva ahí con otro `id`, aparece sola sin borrar lo que ya escribiste.
- **Publicar cambios:** sube el número de `VERSION` en `sw.js` para que la app instalada tome la versión nueva.

Hecho con HTML, CSS y JavaScript sin dependencias. KY SpA · Viña del Mar, Chile.
